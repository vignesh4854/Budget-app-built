# Budget Splitter APK
1. Put your latest app file here named `budget-splitter.html` (replace the old one) and push.
2. The **Build APK** action runs automatically and patches the file for Android itself.
3. Download `app-debug.apk` from the run's **Artifacts**.

`icon.png` (1024x1024) is your app icon - replace it to change the icon.
